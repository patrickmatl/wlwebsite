**A finished logo should come as a small set of files, not one. You need vector files (AI, EPS, PDF and SVG) for anything printed, cut, stitched or enlarged, and raster files (PNG and JPG) for documents, email and social media. Each in full colour, one colour and reversed.** If all you have is a single JPEG that someone emailed you years ago, this guide explains why that keeps causing trouble, which file each supplier actually needs, and what to ask for when a logo is handed over.

## Vector and raster: the one distinction that matters

Every logo file is one of two kinds.

**Vector files** describe the logo as shapes: points joined by lines and curves, filled with colour. Because the file stores instructions rather than dots, the software redraws the logo cleanly at whatever size you ask for. The same file can go on a business card or the side of a building, and the edges stay sharp. AI, EPS, SVG and (usually) PDF are vector formats.

**Raster files** describe the logo as a grid of coloured pixels, like a photograph. They look fine at the size they were saved, but enlarge them and the edges turn soft, then jagged. Shrink them and fine detail disappears. PNG, JPG and WebP are raster formats.

The practical rule follows directly: **keep the vector files as your masters and treat raster files as copies made for a particular use.** You can always make a good PNG from a vector file. You cannot turn a small JPG back into a vector without someone redrawing it by hand, which is exactly why logo redraw services exist.

One trap to know about: saving a JPG inside an AI or PDF file does not make it vector. The file extension looks right, but the logo inside is still pixels. A designer can tell in seconds by zooming in; if the edges go blocky, it is raster.

## The formats, one by one

### AI (Adobe Illustrator)

The native working file of Adobe Illustrator, which is where most logos are drawn. It is fully editable: every shape, colour and letter can be changed. It is the file to keep safe and to hand to any designer who needs to adjust the logo, build a brand identity around it or set up packaging. If you only keep one file, keep this one, plus a PDF so you can see it without special software.

### EPS (Encapsulated PostScript)

An older vector format that almost every design, signage and production program can open. That is its value: signwriters, vinyl cutters, engravers, embroidery digitisers and promotional-goods suppliers often ask for "an EPS" when what they mean is "a vector file I can open".

### PDF (Portable Document Format)

A PDF exported from a vector program keeps the logo as vector artwork, and it opens on any computer or phone. That makes it the most useful single file for printers, and the safest one to email to a supplier who has not said what they need. Note that a PDF can also contain a raster image, so a PDF made by scanning or by "printing to PDF" from a photo is not the same thing.

### SVG (Scalable Vector Graphics)

The vector format built for the web. Browsers draw SVG files directly, so a logo in a website header stays crisp on every screen, from an old laptop to a high-resolution phone, and the file is usually tiny. Web developers will ask for it. SVG is not normally what a printer wants; give them the PDF.

### PNG (Portable Network Graphics)

The everyday raster format for logos, because it supports a **transparent background**. A transparent PNG can sit on a coloured slide, a photo or a dark email footer without a white box around it. Use it in Word and PowerPoint, email signatures, social media posts and anywhere you need to drop the logo onto something else. Ask for PNGs at a few sizes, including a large one, so nobody has to stretch a small one.

### JPG (or JPEG)

A raster format designed for photographs. It compresses files by throwing away detail, which leaves faint smudges around sharp edges and flat colour, exactly what a logo is made of. It also cannot be transparent, so the logo always sits on a solid rectangle. JPG is useful only where a website, form or marketplace refuses anything else. It is never the file to send to a printer or signwriter.

### WebP

A newer raster format, used mainly on websites because it gives smaller files than PNG or JPG at similar quality, and it supports transparency. Your web developer or website platform may convert images to WebP automatically. You do not need a WebP in your logo pack; it is a delivery format for the web, made from your PNG or SVG when needed.

## Colour: RGB, CMYK, HEX and Pantone

Format is half the story. The other half is colour mode, because screens and printing presses make colour in different ways.

- **RGB** (red, green, blue) is how screens produce colour, by mixing light. Files for websites, social media and presentations should be RGB.
- **HEX** codes (like #FFD700) are just RGB colours written as a short code for websites and digital tools. Your brand colours should come with a HEX code each.
- **CMYK** (cyan, magenta, yellow and black) is how most printing works, by layering ink. Print files should be set up in CMYK. Screens can show some bright colours that CMYK ink cannot reach, which is why a vivid screen colour can print a little duller.
- **Pantone** (the Pantone Matching System) is a standard library of numbered, pre-mixed ink colours. When colour accuracy matters across different printers and materials, such as packaging, branded clothing or a colour that is central to the brand, quoting a Pantone reference lets every supplier match the same ink. Not every logo needs one, but if your printer or embroiderer asks for it, you want the reference written down.

A good handover lists each brand colour in all the ways it will be used: CMYK for print, RGB and HEX for screens, and a Pantone reference where the job calls for spot colour. Without that list, the next supplier guesses from a screenshot, and the colour slowly drifts from job to job.

## Which file to send to whom

This is the section to bookmark.

- **Commercial printer** (business cards, brochures, letterheads): the **PDF**, in CMYK. If they want to edit or place it themselves, add the **EPS** or **AI**.
- **Signwriter, vinyl cutter or vehicle branding supplier:** **EPS** or **PDF**. Cutting machines follow vector paths, so a raster file is no use to them. Mention which colours you need and send the colour references.
- **Embroiderer:** the vector file (**EPS** or **PDF**) plus the **single-colour version**. Embroidery shops convert artwork into a stitch file through a process called digitising, and they need clean shapes to do it. Very fine lines and small text often do not survive stitching, so a simplified version helps.
- **Laser engraver, rubber stamp or etching:** the **single-colour vector** file. These processes have one "colour", so a full-colour logo has to be translated anyway.
- **Promotional goods** (pens, mugs, bags): usually **EPS** or **PDF** in one or two colours. Ask the supplier, because printing methods vary.
- **Web developer:** **SVG** for the site header, plus **PNG** for anywhere SVG is not supported and a small square version of the symbol for the browser tab icon (favicon).
- **Social media:** **PNG**, using the square symbol or stacked version for profile pictures, since a long horizontal logo turns unreadable in a small circle.
- **Word, PowerPoint and email signatures:** **PNG** with a transparent background, at a sensible size rather than a huge file scaled down.
- **Online forms and directory listings:** whatever they accept; often **JPG** or **PNG**.

If you are unsure, send the PDF and ask. A supplier who needs something else will say so, and a PDF is never the wrong starting point.

## Logo versions: not just formats

Alongside formats, a usable logo pack covers a few versions of the logo itself:

- **Main logo**: the full version, usually symbol and name together.
- **Alternative layouts** where the design allows: a horizontal layout for website headers and letterheads, and a stacked layout for square spaces.
- **Symbol or icon on its own**, if the logo has one, for social media profiles, app icons and favicons.
- **Full colour, single colour (black) and reversed (white)**, so the logo works on any background and in any process that only prints one colour.

## What you should receive at handover

Use this as a checklist when a designer hands over a logo, whether you work with us or anyone else:

1. **Editable working files** (AI, or the equivalent from the designer's software), so the logo can be changed without starting again.
2. **Vector files** in EPS, PDF and SVG.
3. **Raster files** in PNG (transparent background, several sizes) and JPG.
4. **Each layout** the design has: main, horizontal or stacked, and symbol on its own.
5. **Each colour version**: full colour, single colour and reversed.
6. **Print files in CMYK and screen files in RGB.**
7. **A note of your colours** (CMYK, RGB, HEX, and Pantone where needed) **and the name of the typeface**, so suppliers can match them.
8. **Clear ownership.** You should own the artwork outright once it is paid for, with no licence fee and no need to go back to the designer for permission. If the terms are vague, ask before you pay.

## Frequently asked questions

### What is the best file format for a logo?

There is no single best format; it depends on the use. A vector file (AI, EPS, PDF or SVG) is the master that every other version should come from. For everyday use on screens and in documents, a PNG with a transparent background is usually the right choice.

### Why do my printed colours look different from my screen?

Screens mix light (RGB) and printers mix ink (CMYK), and some bright screen colours cannot be reproduced exactly in ink. Setting print files up in CMYK from the start, and using a Pantone reference where accuracy matters, keeps the difference small and predictable.

### Do I need the AI file if I don't have Adobe Illustrator?

Yes. You may never open it, but the next designer, printer or packaging supplier who needs to edit the logo will. Keep it with your other brand files, and keep a PDF alongside it so you can always view the logo.
